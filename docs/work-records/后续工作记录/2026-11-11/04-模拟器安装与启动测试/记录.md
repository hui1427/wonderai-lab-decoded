## 10. 失败现象、排查过程、重试与最终状态

- **失败现象**：emulator 在无硬件加速下用 `-accel off`（TCG）启动后，adb 持续 offline/not found，qemu 进程近乎零 CPU，随后退出；无法进入 Android。
- **排查过程**：
  1. 确认 `emulator-check accel`=6（无 AEHD/WHPX）与非管理员限制；
  2. 确认 `-help-accel` 要求 `ANDROID_I_WANT_MY_TCG=yes` 才允许 `-accel off`，并按要求设置；
  3. 检查 qemu 进程 CPU 增长与 `-show-kernel` 输出（仅有 QEMU 启动参数与属性日志，无内核 boot 进展）；
  4. 尝试独立 QEMU（DLL 缺失）、ARM 镜像（未下载）。
- **重试**：同参数重试一次（02b），结果相同；未再重复下载/安装其他来源模拟器。
- **最终状态**：**验证失败 / 等待设备或条件**——本机无法在无管理员、无硬件加速、低内存条件下取得可运行的 Android 环境。**这是环境阻塞，不是 APK 缺陷的证据。**
