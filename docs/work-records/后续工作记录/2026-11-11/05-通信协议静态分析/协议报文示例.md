### 1.2 回包解析（关键风险点）

代码行为 **[代码]**：

1. `Scanner$ScanAsyncTask.smali:196-202`：对每个收到的包，若源地址未出现过，则把 `copyOfRange(bytes, deviceIdBeginIndex)` 得到的字节串作为设备 ID 字符串放入 `Map<InetAddress,String>`；
2. `deviceIdBeginIndex` 恒为 0（`:44-47`，`Scanner$ScanAsyncTask.smali:30` 字段，构造器固定置 0）；
3. `Scanner.smali:227-266` 的 `copyOfRange` 逻辑：

4. `SearchDeviceActivity$1.smali:141-152`：把该字符串放入列表 `item_id`，把回包源 IP 放入 `item_ip`；

### 2.3 心跳与断连的实际节律（以雷达页为例）**[代码 + 推断]**

- 页面 `Timer` 每 **50 ms** 执行一次 `TimerTask`（`activity/JetRover/JetRoverRadarActivity.smali:179-196`，`schedule(task, 0, 0x32)`）；
- `TimerTask.run()` 内计数，达到阈值后 `Handler.sendMessage(what=5)`（`activity/JetRover/JetRoverRadarActivity$12.smali:116-155`；10 次 tick → 每 500 ms 一次 what=5）；
- `MsgCallBack` 收到 what=5 后计数，累计 ≥4（`const/4 0x4`）才发一次心跳并清零（`activity/JetRover/JetRoverRadarActivity$MsgCallBack.smali:90-149`）；
- 由此推算：雷达页心跳周期约 **2 s**（**[推断]**，需真机抓包确认；不同页面的计时器参数不同，未逐页换算）。
- 断连：无自动重连；`onClose/onError` 只打印日志；退出页面/`onPause` 主动 `close()`（证据见 2.1）。

## 3. HTTP JSON-RPC（`http://<deviceIp>:9030/`）

### 3.1 请求

**HTTP 层** **[代码]**（`com/deng/netlibrary/netLib/ZyNetHttps.smali:695-1092`，`$Builder.smali`）：

```http
POST http://<deviceIp>:9030/ HTTP/1.1
deviceid: you device id
X-JSON-RPC: <method>
er: false
dr: false
Content-Type: text/x-markdown; charset=utf-8
```

- `deviceid` 头是**硬编码占位串** `"you device id"`（`ZyNetHttps.smali:995-1000`）——这是兼容性高风险点（见未决问题）；
- `er`/`dr` 分别为 `isOutputDecryption`/`isInputDecryption` 的字符串值（`:177-178`），默认 `false`；
- `X-JSON-RPC` = method（`:1004-1007`）；
- OkHttp 超时：connect/write/read 由 Builder 的 `cTime/wTime/rTime` 秒数决定（`:129-132`，默认值见 `$Builder.smali` 构造器）。

**Body 层** **[代码]**（`utils/AESHelper.smali:401-486` + `model/RPCRequestModel.smali`）：

```json
{"id":<System.currentTimeMillis()>,"jsonrpc":"2.0","method":"<method>","params":<params>}
```

- `id` 为请求时刻毫秒数（`currentTime`，`ZyNetHttps.smali:774-779`）；
- `jsonrpc` 固定 `"2.0"`（`RPCRequestModel.smali:51-54`）；
- `params` 按 Builder 的 `type` 分支取不同参数类型（`paramsByAES` / `_String` / `_float` / `_Map`，`ZyNetHttps.smali:846-971`）；
- 若 `isInputDecryption=true`，`params` 会被替换为 AES 加密后的 Base64 字符串；默认 `false` 时 `params` 就是原始 JSON 值（`AESHelper.smali:421-444`）。

**实例（AiNex 控制页，`method=RunAction`）** **[代码]**：

- 参数形态：`String[]`，如 `["<action>","1"]` 或 `["8","<action>"]`（`activity/AiNex/AiNex_Control_Activity$2.smali:62-133`）；
- 请求体模板：

```json
{"id":<毫秒时间戳>,"jsonrpc":"2.0","method":"RunAction","params":["<action>","1"]}
```

- 其余 method 名（静态可见，均为代码原文）：`RunAction`、`StandUp`、`StopFunc`、`StartFunc`、`LoadFunc`、`UnloadFunc`、`SetBusServoPulse`、`SetPWMServo`、`SetBallColor`、`SetLadderColor`、`SetTargetTrackingColor`、`SetVisualPatrolColor`、`GetLABValue`、`SetLABValue`、`SaveLABValue`（停止用 `StopFunc`）。
  - 证据：`activity/AiNex/AiNex_Control_Activity.smali:952,1055,1585,1952,1987,2860`；`activity/AiNex/AiNex_Control_Activity$1.smali:80,132`；`activity/AiNex/AiNex_Automatic_Kick_Activity.smali:723,1298`；`activity/RPC_SetThresholdActivity.smali:519,1012,1273`

### 3.2 响应处理（代码模型，非实测报文）**[代码]**

- 响应读入后由 `ZyRpcCallback$1.run()` 处理：`AESHelper.decryptionByAES(isOutputDecryption, body)` → 默认 `false` 直接返回原文 → `Gson.fromJson(body, RPCBaseModel.class)`（`callback/ZyRpcCallback$1.smali:47-100`）；
- `RPCBaseModel` 字段（Gson 按字段名映射）：`id`(String)、`jsonrpc`(String)、`result`(RPCBaseResultModel)、`error`(RPCServerErrorModel)（`model/RPCBaseModel.smali:33-47`）；
- `result` 子对象字段名首字母大写：`Error`、`List`、`Obj`、`Property`（`model/RPCBaseResultModel.smali:24-58`）；
- `error` 子对象：`name`、`message`（`model/RPCServerErrorModel.smali:21-25`）；
- 业务回执：`StrResponseHandler.onSuccess` → `handleRecvMessage(String)`（例：`activity/AiNex/AiNex_Control_Activity$8.smali:47-55`、`activity/AiNex/AiNex_Control_Activity.smali:484`）。

**响应模板（由模型字段拼出，未验证真实设备使用该结构）**：

```json
{"id":"<同请求id或服务端id>","jsonrpc":"2.0","result":{"Obj":<...>,"Property":<...>,"List":<...>,"Error":<...>},"error":null}
```

**未验证/需真机抓包**：服务端是否校验 `deviceid: you device id`；`X-JSON-RPC` 与 body method 不一致时行为；`result.Obj` 的真实内容；错误码；`id` 类型（请求为数字、响应模型为字符串）是否被 Gson 接受。
