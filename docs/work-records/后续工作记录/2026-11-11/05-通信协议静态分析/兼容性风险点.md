# 兼容性风险点清单（通信协议静态分析产出，供 Lead 汇总）

> 分级：**高** = 可能直接导致真机功能不可用/崩溃；**中** = 特定机型/网络/系统版本下失败或体验差；**低** = 信息性/可改进。
> 证据类型：[代码] 直接读到；[推断] 由代码结构推出；[实测] 本轮无真机 = 0 条。
> 路径均相对工程根 `RobotLab/`。
