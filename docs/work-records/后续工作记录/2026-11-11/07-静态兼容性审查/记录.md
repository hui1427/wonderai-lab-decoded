## 7. 构建、签名、安装与测试的实际输出及结果

扫描结果汇总（`compat-scan.json`）：

| 模式 | 命中 | 需要关注的结论 |
|---|---|---|
| `registerReceiver` 两参调用 | 3（app 代码 2 处：`SetNetActivity`、`BLEManager`） | 注册的 action 全部是 **系统广播**（`android.net.wifi.*`、`android.net.conn.CONNECTIVITY_CHANGE` 等，`SetNetActivity.smali:724-752`）。Android 14 对两参注册器的导出强制要求**只针对非系统广播**，系统广播不受影响 → 不构成启动崩溃。`BLEManager` 属死代码（见下） |
| `PendingIntent.get*` 调用 | 3（全部在 androidx `MediaSessionCompat`/`SearchView`/`MediaButtonReceiver` 库内，**app 代码 0 处**） | 无 Android 12 `FLAG_IMMUTABLE` 崩溃面（app 不使用 PendingIntent） |
| 动态广播接收器 | 同上 | 无 `RECEIVER_EXPORTED` 相关问题 |
| 外部存储 API | app 代码 0 处 `getExternalStorageDirectory`；`SearchDeviceActivity.verifyStoragePermissions()` 会请求 `READ/WRITE_EXTERNAL_STORAGE`，但 **Manifest 未声明这两个权限**，且方法整体 `try/catch`（`SearchDeviceActivity.smali:1817-1850`），无 `onRequestPermissionsResult` 处理 | 权限请求会立即返回拒绝，但不会崩溃；属遗留代码，功能不依赖它 |
| 蓝牙/BLE | `SearchDeviceDialog` 调 `startLeScan`/`getBondedDevices`；`BLEService` 存在；但 **Manifest 无任何 BLUETOOTH/BLUETOOTH_SCAN/CONNECT 权限** | **BLE 为死代码**：① `SearchDeviceDialog` 在整个 smali 中**没有外部引用**（仅自身内部类）；② `BLEService` 在 app 代码中**从未 startService/bindService**；③ `TitleActivity.onCreate` 只是 `new Intent(...)` 后未使用。故 BLE 缺失权限不影响现有功能；若后续要启用 BLE，必须补 `BLUETOOTH_SCAN`/`BLUETOOTH_CONNECT`（Android 12+ 运行时）与旧版权限 |
| 包可见性（Android 11+） | app 代码 0 处 `getInstalledPackages/queryIntentActivities`（仅 androidx 库内部） | 无需 `<queries>`；无相关风险 |
| WebView | 大量使用（视频/阈值页面：`WebView.loadUrl` 播放 MJPEG） | `usesCleartextTraffic="true"`（原版即有）允许 http 视频流；无混合内容拦截问题 |
| 前台服务/通知/闹钟 | app 代码 0 处 `startForegroundService`/`AlarmManager`（仅库） | 无 Android 12+ 前台服务启动限制、Android 13 通知权限相关崩溃面 |
| ContentProvider / FileProvider | Manifest 无 `<provider>`；app 代码无 `content://` 常量 | 无 Android 12 `android:exported` 缺省崩溃面 |
| 组件导出 | 138 个组件（137 Activity + 1 Service）；**仅 `StartActivity` `exported=true` 且有 LAUNCHER intent-filter**，其余 Activity 均无 filter | 符合 Android 12+ 要求；无 `exported` 缺失导致的安装失败 |

### 7.2 原生库与 16KB 页

| ABI | 文件 | PT_LOAD p_align | 判断 |
|---|---|---|---|
| arm64-v8a | `libpl_droidsonroids_gif.so` | **65536 (64KB)** | 兼容 Android 15+ 16KB 页设备 |
| x86_64 | 同名 | **4096 (4KB)** | 仅 4KB 页 x86_64 环境可加载；16KB 页 x86_64 模拟器/设备会加载失败（真机 arm64 不受影响） |
| armeabi / armeabi-v7a / x86 | 同名 | ELF32（未解析） | 32 位，现代真机基本不用 |

APK 侧 `zipalign -P 16 4` 已通过（见 01），未压缩 .so 满足 16KB 对齐；arm64 真机无 16KB 页风险。

### 7.3 Android 版本行为对照（静态评估）

| Android 版本 | 行为变更 | 本 App 影响 | 证据/结论 |
|---|---|---|---|
| 5.0 (minSdk 21) | — | 可安装 | badging minSdk=21 |
| 6~12 | 运行时权限（位置） | WiFi 扫描需要位置权限；`SearchDeviceActivity.grantPermm()` 请求 `ACCESS_FINE_LOCATION`（Manifest 已声明） | `SearchDeviceActivity.smali:710-744`、Manifest 权限；**需真机确认**用户授予后能否正常扫描 |
| 9+ | 明文流量默认禁止 | Manifest `usesCleartextTraffic="true"`（原版即有） | `AndroidManifest.xml:14`；视频 http 流不受影响 |
| 10+ | 分区存储 | 照片/视频走 WebView + HTTP，不写公共存储；请求的存储权限未声明且被 try/catch 吞掉 | 无写入公共存储的 app 代码；风险低 |
| 11+ | 包可见性 | app 不查询其它包 | 无影响 |
| 12+ | 组件 exported 必填 / PendingIntent 可变性 / 前台服务限制 | 仅 launcher 导出；无 PendingIntent；无前台服务 | 无崩溃面 |
| 13+ | 通知运行时权限 | app 不发通知 | 无影响 |
| 14+ | 动态接收器导出标志 | `SetNetActivity` 只注册系统广播，属豁免 | 无崩溃面（若未来改成自定义广播需加 flag） |
| 15+ | 强制 edge-to-edge、16KB 页 | 界面为全屏横版自定义布局，可能出现状态栏/导航栏遮挡的视觉差异；arm64 .so 已 64KB 对齐 | 视觉需真机确认；无崩溃证据 |
| 16 (targetSdk 36) | 大屏忽略方向锁定、预测性返回默认 | 全部 Activity `screenOrientation="landscape"`；在平板/折叠屏上系统可能强制可旋转，横版布局可能错位；返回手势动画变化 | 静态推断，**需平板/折叠屏真机确认** |
| 任意 | BLE 权限缺失 | BLE 死代码，不影响主流程 | 见 7.1 表 |
