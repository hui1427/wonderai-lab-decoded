| 状态 | 判定条件 |

## 1. 通用准备



1. 准备两台可横屏 Android 手机（或一台手机+一台平板），Android 7.0+，同一 WiFi 网络；保留原版 `com.hiwonder.wonderai`，安装新版 `local.robotlab.wonderai`（`builds/<日期时间>/WonderAi-Lab.apk`）。

2. 首次启动授予定位/存储/相机等权限；确认桌面出现两个独立入口，应用名分别为 WonderAi 与 WonderAi Lab。

3. 记录 APK SHA-256（新版与交付件一致），记录手机型号/Android 版本。

4. 机器人上电、连接同一网络；记录机器人型号与固件版本、IP。

5. 安全工位：机械臂/底盘/六足活动范围内清空，急停可用，人员监护；视觉测试准备色块/标签/垃圾/字母数字块等道具。



## 2. 通用连接主流程（P0，所有机型）



1. 启动页（`StartActivity`）：启动图显示、不崩溃、自动进入主界面。

2. 套件选择（`MainActivity`）：初阶/进阶/高阶/专业套件四类按钮可切换；页面含产品列表（item_in_movicetype）。

3. 产品选择（仅 JetHexa/JetRover/ROSOrin）：`JetHexaHomePageActivity` / `JetRoverProductHomePageActivity` / `ROSOrinProductHomePageActivity` → 选择子型号。

4. 设备搜索（`SearchDeviceActivity`）：显示“正在搜索...”；原版与新版能否发现同一设备；记录发现耗时、失败重试；UDP 本地 9025/目的 9027、探测文本 `LOBOT_NET_DISCOVER`（静态证据，见 05 任务）。

5. 连接成功后按机型进入对应首页（各机型入口行号见下表）。

6. 网络配置：`SetNetActivity`（WiFi 列表/连接）、`DirectConnectionModeActivity`（直连/局域网模式配置）。

## 3. 逐页通用检查项（每个页面都要做）



1. 页面能否打开、标题/布局是否正常、有无闪退。

2. 页面内视频是否出现（多数控制/视觉页含 WebView 视频）；拍照按钮能否保存并进入照片列表/查看。

3. 按钮/滑杆/开关是否有响应；返回键与标题栏返回是否正常，返回后上一页是否仍在连接状态。

4. 断网/断开机器人后页面表现（提示/重连/不崩溃）；重新连接后是否可继续操作。

5. 与同页原版对比：界面差异、按钮差异、默认参数差异，逐条记录。

6. 每页至少 1 张截图（含标题）+ 失败时 logcat；命名：`<序号>-<机型>-<页面>-<时间>.png`。
