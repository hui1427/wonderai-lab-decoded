# 兼容版命名调整记录

按用户要求，对 RobotLab 兼容版创建独立副本，在不覆盖原工程的前提下调整安装身份、应用入口及相关类命名空间。旧包名改为 com.selfvehicle.compat，控制页改为 com.selfvehicle.compat.activity.ROSOrin.ROSOrinProControlActivity，WonderAiApplication 改为 VehicleApplication。README 说明此工程来自已有第三方应用，apktool.yml 移除解包工具版本字段，并将该改名版本设为 0.1.0。保留原始工作记录与旧项目。

共调整 1667 个文件。通过 Apktool 完成重建，使用独立开发签名签名，v1/v2/v3 和 zipalign 验证通过。DEX 中按新命名空间映射后，6563 个类、61802 个方法引用与原兼容版集合一致，assets/lib 的 SHA-256 一致。这是静态检查，不能证明运行时行为全部一致。

已知界限：代码、资源和部分厂商协议/文案仍来自旧应用；改名本身不能让代码成为自主开发。本机 ADB 没有检测到手机，未安装或启动改名版本，未验证机器人通信。此前 dsh-purge 安装脚本下载被自动审批以 blocked by policy 拒绝，本次未安装该插件。

交付文件：outputs/Vehicle-Control-Compat.apk 和 outputs/Vehicle-Control-Compat-Project.zip。完全独立编写的初版在 outputs/SelfVehicle/。
