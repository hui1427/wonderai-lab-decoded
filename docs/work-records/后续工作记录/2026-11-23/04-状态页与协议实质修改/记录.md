# 兼容版新增自研状态页与协议

用户指出先前交付主要是原 APK 改名、重签名，没有兑现修改界面和通信协议的表述。这一判断成立。本次在改名兼容工程副本上增加实际功能，保留先前版本。

## 界面和代码

首页 `res/layout/activity_main.xml` 增加“自研状态”按钮，通过 `MainActivity.openSelfVehicle` 打开独立编写的 `com.selfvehicle.control.MainActivity`。新页包含地址输入、连接、断开、刷新及车辆标识、电压、电量、运行状态等字段。Manifest 登记该页面。新页使用的独立 Java 代码与车载服务源码放在项目的 `selfvehicle-source/`，同时转换成 Smali 集成到 APK。最低系统版本从 API 21 改为 API 26，工程版本为 0.2.0。

## 通信功能

新增独立状态读取接口 `GET /api/v1/status`，支持输入热点或同一 Wi-Fi 网络的车端 IP 和端口，要求状态 schema 为 `selfvehicle.status.v1`。`selfvehicle-source/vehicle/vehicle_service.py` 是可在车载电脑运行的 Python 状态服务，车辆标识由参数指定，未接入时电池为 null、串口状态为未接入。旧机器人控制页的 ROS/WebSocket 协议和旧控制行为仍然保留。本次没有实现真实运动或夹爪控制。

## 验证

重建日志、Manifest 和首页布局回读、签名和成果哈希保存于本目录。APK 的首页布局回读显示按钮与回调，Manifest 含新增页面，DEX 含独立 Activity、StatusClient 和 `/api/v1/status`。从最终 DEX 反汇编的 11 个自研 Smali 文件与集成前文件逐字节一致。独立 Java 客户端的测试与 Python 车载服务、模拟服务的本机 HTTP 联调通过，模拟电池分别验证 7000 mV/42% 和 8400 mV/100%。APK 通过 v2、v3 签名和 zipalign 校验。最低 Android 系统版本为 26。

上述测试未在实际 Android APK 中执行请求，本机 ADB 没有检测到设备；按钮在真实界面是否正常、热点/Wi-Fi 和实际车辆通信仍待验证。此工程仍包含第三方原版代码和资源，改名不改变其来源。
