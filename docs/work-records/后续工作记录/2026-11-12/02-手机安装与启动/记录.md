# REDMI K80 安装和启动

手机通过 ADB 授权连接，系统 Android 16，API 36。安装前确认原版包已存在，兼容版包未列出。执行 adb install -r outputs/WonderAi-Lab.apk，返回 Success。执行 am start 启动兼容版 StartActivity，等待约 8 秒后，系统记录 topResumedActivity 为兼容版 MainActivity。原版和兼容版包均在已安装列表。启动期间检查最近 AndroidRuntime 错误输出未见匹配该包的异常。

本次验证了安装及系统记录的首页启动，未验证原版启动、界面视觉、设备连接或机器人功能。未记录手机序列号。安装包哈希见上一项设备检查记录。


用户反馈：手机屏幕已显示 WonderAi Lab 主界面。界面细节和机器人连接尚未验证。
